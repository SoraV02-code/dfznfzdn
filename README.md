# Para ti, mi amor

Página web romántica y divertida para responder tres preguntas con un botón “No quiero” que intenta escapar del puntero.

## Ejecutar

Abre `index.html` directamente en un navegador, o ejecuta un servidor local:

```bash
python -m http.server 8000
```

Después abre `http://localhost:8000`.

## Archivos

- `index.html`: estructura de la página.
- `styles.css`: diseño, animaciones y diseño responsive.
- `script.js`: preguntas, interacción y efecto del botón evasivo.
